DNA Foci Detector for Apple Silicon Macs

1. Extract DNA_Foci_Detector_macOS_AppleSilicon.zip.
2. Control-click DNA Foci Detector and choose Open.
3. Confirm Open when macOS asks.

If macOS still blocks the first launch, open System Settings, select Privacy &
Security, and choose Open Anyway for DNA Foci Detector. This is required only
for the first launch because this lab build is ad-hoc signed, not notarized.

Keep the application in a local folder such as Applications or Desktop. Python
is not required. Cellpose runs on the CPU and both supported models are bundled.

CSV output is written beside the first selected image. Source images are never
modified.
